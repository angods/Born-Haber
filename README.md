## ✨ ¿Qué es?

Una animación que muestra el **ciclo de Born-Haber del cloruro de sodio** con átomos, electrones y un medidor de energía que sube y baja en cada etapa. Sirve para entender *por qué* se calcula así la **energía reticular (U)**.

## 🔄 Las etapas

| Paso | Proceso | ΔH |
|---|---|---|
| 🏁 | **Punto de partida** — Na(s) + ½ Cl₂(g) | — |
| 1️⃣ | 🔥 **Sublimación del sodio** — Na(s) → Na(g) | +107 kJ/mol |
| 2️⃣ | 🔥 **Disociación del cloro** — ½ Cl₂(g) → Cl(g) | +122 kJ/mol |
| 3️⃣ | 🔥 **Ionización del sodio** — Na(g) → Na⁺(g) + e⁻ | +496 kJ/mol |
| 4️⃣ | ❄️ **Afinidad electrónica del cloro** — Cl(g) + e⁻ → Cl⁻(g) | −349 kJ/mol |
| 5️⃣ | 🧊 **Formación de la red** — Na⁺(g) + Cl⁻(g) → NaCl(s) | U = ? |

🔥 = absorbe energía · ❄️ = libera energía
